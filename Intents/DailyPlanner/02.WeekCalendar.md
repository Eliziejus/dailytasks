# 2. WeekCalendar

**Goal**: Render the current week's 7 days as a strip; navigate prev/next week; select a day.
**Est.**: 1.5h
**Dependencies**: PageShell

## Steps
- [ ] Compute the current week's 7 dates (Mon–Sun) in `js/app.js`
- [ ] Render each day as a clickable element in `#week-strip` (date, weekday label)
- [ ] Add prev/next week buttons that shift the displayed week
- [ ] Highlight the selected day; default to today on load

## Definition of Done
- [ ] Week strip shows 7 correct dates for the current week
- [ ] Prev/next buttons move the strip by 7 days
- [ ] Clicking a day highlights it and stores it as the "selected day"
