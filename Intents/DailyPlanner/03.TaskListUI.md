# 3. TaskListUI

**Goal**: Render the selected day's tasks in `#day-detail` from in-memory sample data.
**Est.**: 1h
**Dependencies**: WeekCalendar

## Steps
- [ ] Define an in-memory tasks data structure keyed by date (array of `{id, title, time, notes, done}`)
- [ ] Render task list for the selected day, sorted by time
- [ ] Show title, time, notes, and a done checkbox per task
- [ ] Show an empty-state message when a day has no tasks

## Definition of Done
- [ ] Selecting different days in the week strip updates the visible task list
- [ ] Tasks display title/time/notes correctly, sorted by time
