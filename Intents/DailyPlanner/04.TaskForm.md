# 4. TaskForm

**Goal**: Add a form/modal to create a new task or edit an existing one for the selected day.
**Est.**: 1.5h
**Dependencies**: TaskListUI

- [ ] Wire form submit to add a new task to the selected day's data and re-render the list
- [ ] Add an "edit" action per task that opens the same form pre-filled, saves changes on submit
- [ ] Basic validation: title required

## Definition of Done
- [ ] Can add a new task to the selected day and see it appear in the list
- [ ] Can edit an existing task's title/time/notes and see the update reflected
