# 6. Persistence

**Goal**: Persist all tasks to localStorage so they survive a page reload.
**Est.**: 1h
**Dependencies**: TaskActions

## Steps
- [ ] Define a localStorage key/schema for tasks keyed by date
- [ ] Load tasks from localStorage on page load (fall back to empty state if none)
- [ ] Save to localStorage on every add/edit/toggle/delete
- [ ] Handle malformed/missing localStorage data gracefully

## Definition of Done
- [ ] Adding/editing/completing/deleting a task persists across a page reload
- [ ] Fresh browser (no existing data) loads cleanly with empty state
