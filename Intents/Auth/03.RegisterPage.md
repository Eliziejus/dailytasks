# 3. RegisterPage

**Goal**: A `register.html` page where a new user creates an account.
**Est.**: 1h
**Dependencies**: FirebaseSetup

## Steps
- [x] `register.html`: email, password, confirm-password fields, submit button, link to `login.html`, error message area
- [x] `src/js/register.js`: on submit, validate passwords match and meet Firebase's minimum length (6 chars), call `createUserWithEmailAndPassword`; Firebase signs the user in automatically on success — redirect to `index.html`
- [x] Surface Firebase errors inline (email already in use, weak password, invalid email)
- [x] If a user is already signed in and lands on `register.html`, redirect straight to `index.html`

## Definition of Done
- [x] Registering a new account signs the user in and lands on the planner
- [x] Mismatched passwords / weak password / duplicate email all show inline errors and do not create a broken auth state
- [x] Already-authenticated visitors are bounced straight to the planner
