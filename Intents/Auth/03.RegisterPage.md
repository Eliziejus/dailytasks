# 3. RegisterPage

**Goal**: A `register.html` page where a new user creates an account.
**Est.**: 1h
**Dependencies**: FirebaseSetup

## Steps
- [ ] `register.html`: email, password, confirm-password fields, submit button, link to `login.html`, error message area
- [ ] `src/js/register.js`: on submit, validate passwords match and meet Firebase's minimum length (6 chars), call `createUserWithEmailAndPassword`; Firebase signs the user in automatically on success — redirect to `index.html`
- [ ] Surface Firebase errors inline (email already in use, weak password, invalid email)
- [ ] If a user is already signed in and lands on `register.html`, redirect straight to `index.html`

## Definition of Done
- [ ] Registering a new account signs the user in and lands on the planner
- [ ] Mismatched passwords / weak password / duplicate email all show inline errors and do not create a broken auth state
- [ ] Already-authenticated visitors are bounced straight to the planner
