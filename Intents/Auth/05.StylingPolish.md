**Goal**: Make login/register/logout visually consistent with the existing planner UI, with clear error/loading states.
**Est.**: 1h
**Dependencies**: LoginPage, RegisterPage, AuthGuard

## Steps
- [ ] Extend `src/css/styles.css` (or add `src/css/auth.css`, linked from `login.html`/`register.html`) reusing existing tokens/classes (buttons, inputs, error text) rather than inventing a parallel style language
- [ ] Style the auth forms' error state to match `#task-form-error` conventions already in the app
- [ ] Style the header's user-email + logout button consistently with `.app-header`

## Definition of Done

- [ ] Forms are usable and legible at mobile widths
- [ ] Errors and loading states are visually distinct and accessible (not color-only)
