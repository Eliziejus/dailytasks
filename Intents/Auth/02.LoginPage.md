# 2. LoginPage

**Goal**: A `login.html` page where an existing user signs in with email/password.
**Est.**: 1h
**Dependencies**: FirebaseSetup

## Steps
- [ ] `login.html`: email + password fields, submit button, link to `register.html`, error message area (mirrors the existing `task-dialog` form markup/conventions in `index.html`)
- [ ] `src/js/login.js`: on submit, call `signInWithEmailAndPassword`; on success redirect to `index.html`; on failure show a human-readable error (invalid credentials, unknown user, etc.) without leaking which field was wrong
- [ ] Basic client-side validation: both fields required, email format
- [ ] If a user is already signed in and lands on `login.html`, redirect straight to `index.html`

## Definition of Done
- [ ] Submitting valid credentials signs the user in and lands on the planner
- [ ] Submitting invalid credentials shows an inline error and keeps the user on the page
- [ ] Already-authenticated visitors are bounced straight to the planner
