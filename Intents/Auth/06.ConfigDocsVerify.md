# 6. ConfigDocsVerify

**Goal**: Document how the user creates their own Firebase project and wires up `firebase-config.js`, and give them a manual QA checklist since Claude cannot create third-party credentials or run a live Firebase project.
**Est.**: 0.5h
**Dependencies**: FirebaseSetup, LoginPage, RegisterPage, AuthGuard

## Steps
- [x] Add a "Setting up auth" section to `README.md`: create a Firebase project, enable Email/Password sign-in under Authentication → Sign-in method, copy the web config into `src/js/firebase-config.js`
- [x] Note the deployment gotcha: whichever domain the site is deployed to (GitHub Pages/Netlify) must be added to Firebase's Authorized Domains list, or sign-in will fail there even though it works on `localhost`
- [x] Provide a short manual QA checklist for the user to run once their config is in place: register a new account, log out, log in, refresh while signed in, visit `index.html` signed out directly by URL

## Definition of Done
- [x] A user with zero Firebase experience can follow the README and get a working project config
- [x] The manual QA checklist covers every Definition of Done bullet from intents 2–4
