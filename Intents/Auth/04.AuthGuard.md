# 4. AuthGuard

**Goal**: Gate the existing planner (`index.html`) behind auth, and let a signed-in user log out.
**Est.**: 1h
**Dependencies**: FirebaseSetup, LoginPage

## Steps
- [ ] In `index.html` (or a small new `src/js/auth-guard.js` imported first), subscribe to `onAuthStateChanged`; if signed out, redirect to `login.html` before the planner UI renders
- [ ] While the auth state is still resolving on first load, show a brief loading state instead of a flash of the planner UI
- [ ] Add a "Log out" button to the app header, wired to `signOut`, redirecting to `login.html` afterward
- [ ] Show the signed-in user's email somewhere in the header

## Definition of Done
- [ ] Visiting `index.html` while signed out redirects to `login.html`
- [ ] Visiting `index.html` while signed in shows the planner, unchanged from before this feature (`app.js` task logic untouched)
- [ ] Logging out redirects to `login.html` and a subsequent visit to `index.html` redirects again (no stale session)
