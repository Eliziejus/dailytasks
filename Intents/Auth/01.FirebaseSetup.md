# 1. FirebaseSetup

**Goal**: Wire the Firebase Auth SDK into the project via CDN ES modules and provide a single place for the user's project config, without introducing a build step.
**Est.**: 0.5h
**Dependencies**: none

## Steps
- [x] Create `src/js/firebase-config.js` exporting the Firebase web config object, with clearly-marked placeholder values and a comment pointing to Firebase Console → Project Settings
- [x] Create `src/js/firebase.js` that imports `firebase-config.js`, initializes the Firebase app via CDN `import` (`https://www.gstatic.com/firebasejs/.../firebase-app.js` + `firebase-auth.js`), and exports the initialized `auth` instance plus the auth functions used later (`onAuthStateChanged`, `signInWithEmailAndPassword`, `createUserWithEmailAndPassword`, `signOut`)
- [x] Confirm `index.html`, `login.html` (created in intent 2), `register.html` (intent 3) can all `import` from `firebase.js` as an ES module (`<script type="module">`)

## Definition of Done
- [x] `firebase.js` initializes without console errors once real config values are present (cannot verify with placeholders — see intent 6)
- [x] Config values live in exactly one file (`firebase-config.js`) so the user only has to edit one place

Cannot verify against a live project until the user fills in real config values (deferred to intent 6).
