# 1. WireGoogleSignIn

**Goal**: Add a working "Continue with Google" button to both auth pages.
**Est.**: 0.5h
**Dependencies**: Auth

## Steps
- [ ] Extend `firebase.js` to import and re-export `GoogleAuthProvider` and `signInWithPopup`
- [ ] Add a "Continue with Google" button (with a divider) to `login.html` and `register.html`, above or below the existing form
- [ ] Add a shared `signInWithGoogle()` call in both `login.js` and `register.js`: on click, `signInWithPopup(auth, new GoogleAuthProvider())`, redirect to `index.html` on success
- [ ] Handle `auth/popup-closed-by-user` and `auth/cancelled-popup-request` silently (no error shown — the user just changed their mind), and show a human-readable error for anything else (e.g. `auth/account-exists-with-different-credential`)

## Definition of Done
- [ ] Clicking the button on either page opens the Google popup and, on success, lands on the planner
- [ ] Closing the popup without completing sign-in leaves the user on the page with no error message
- [ ] Existing email/password form and validation are unaffected
