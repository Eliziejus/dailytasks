# 1. WireGoogleSignIn

**Goal**: Add a working "Continue with Google" button to both auth pages.
**Est.**: 0.5h
**Dependencies**: Auth

## Steps
- [x] Extend `firebase.js` to import and re-export `GoogleAuthProvider` and `signInWithPopup`
- [x] Add a "Continue with Google" button (with a divider) to `login.html` and `register.html`, above or below the existing form
- [x] Add a shared `signInWithGoogle()` call in both `login.js` and `register.js`: on click, `signInWithPopup(auth, new GoogleAuthProvider())`, redirect to `index.html` on success
- [x] Handle `auth/popup-closed-by-user` and `auth/cancelled-popup-request` silently (no error shown — the user just changed their mind), and show a human-readable error for anything else (e.g. `auth/account-exists-with-different-credential`)

## Definition of Done
- [x] Clicking the button on either page opens the Google popup and, on success, lands on the planner
- [x] Closing the popup without completing sign-in leaves the user on the page with no error message
- [x] Existing email/password form and validation are unaffected

## Outcome (fill after Iterate)
- **Actual Time**:
- **Result**: Added a small `google-auth.js` module (mirrors the `tasks-repo.js` pattern — a thin domain wrapper over the raw `firebase.js` SDK exports) with `signInWithGoogle()` and `isBenignPopupError()`. Restructured `login.html`/`register.html`: `.auth-form` is now an outer wrapper div (Google button → divider → the actual `<form>` → switch link) instead of the form itself, since the Google button needed to live outside the email/password `<form>` without triggering its submit/validation. `auth.css` updated accordingly (`.auth-form form` now carries the flex/gap that used to be on `.auth-form` directly) plus new `.google-btn`/`.auth-divider` styles. Both pages reuse their existing `#login-form-error`/`#register-form-error` element for Google errors too — no new error UI needed. Verified via Playwright: both pages render with the button, no console errors, `index.html` still redirects correctly.
- **Follow-ups**: None beyond the deferred live-project verification (needs the Google provider enabled in the user's Firebase project).
