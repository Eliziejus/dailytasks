# 1. FirestoreSetup

**Goal**: Wire the Firestore SDK into the existing Firebase init, and settle the data model and security rules before writing any app code against them.
**Est.**: 0.5h
**Dependencies**: Auth (FirebaseSetup)

## Steps
- [ ] Extend `src/js/firebase.js` to import `getFirestore` and the Firestore functions the app will need (`collection`, `doc`, `addDoc`, `updateDoc`, `deleteDoc`, `setDoc`, `getDoc`, `onSnapshot`, `writeBatch`, `serverTimestamp`) from the same pinned Firebase SDK version already used for Auth, and export the initialized `db` instance
- [ ] Define the data model: one document per user at `users/{uid}` (holds a `migratedFromLocalStorage` flag), with a `tasks` subcollection at `users/{uid}/tasks/{taskId}` — each task doc: `{ title, time, notes, done, date }` (`date` is the `YYYY-MM-DD` key the app already uses)
- [ ] Write the Firestore security rules that scope all reads/writes to the signed-in user's own `users/{uid}` document and subcollection, for the user to paste into the Firebase console (documented in intent 6, not something Claude can apply remotely)

## Definition of Done
- [ ] `firebase.js` exports a working `db` handle alongside the existing `auth` handle
- [ ] The data model and security rules are written down and ready to hand to the user in intent 6
